# Abdulgeni Abdulaziz — Portfolio

Full Stack AI Engineer portfolio built with Next.js, featuring a live AI assistant, GitHub stats integration, and interactive project case studies.

## Tech Stack
Next.js · React · TypeScript · Tailwind CSS · Framer Motion · Three.js

## Run Locally

**Prerequisites:** Node.js 20.19+

1. Install dependencies:
   \`\`\`bash
   npm install
   \`\`\`
2. Copy `.env.example` to `.env.local` and fill in your API keys:
   \`\`\`bash
   cp .env.example .env.local
   \`\`\`
3. Run the dev server:
   \`\`\`bash
   npm run dev
   \`\`\`
